# Exemplos de IA supervisionada e não supervisionada

Projeto simples para a matéria de Inteligência Artificial, com dois exemplos em Python:

- IA supervisionada: classificação de crédito usando KNN.
- IA não supervisionada: segmentação de clientes usando K-Means.

A proposta foi manter tudo didático e sem dependências externas. Assim, basta ter Python instalado para executar.

## Como executar

Na raiz do projeto, rode:

```bash
python main.py
```

Também é possível executar cada exemplo separadamente:

```bash
python exemplos/supervisionado_knn_credito.py
python exemplos/nao_supervisionado_kmeans_clientes.py
```

## Exemplo 1, IA supervisionada

Arquivo: `exemplos/supervisionado_knn_credito.py`

O modelo usa uma base fictícia de clientes com:

- renda mensal
- idade
- score de crédito
- dívida atual
- rótulo conhecido, `aprovado` ou `negado`

Como já existe uma resposta correta para cada cliente, o algoritmo aprende comparando um novo cliente com clientes antigos. Por isso é um exemplo supervisionado.

Algoritmo usado: KNN, ou K vizinhos mais próximos.

Impacto prático: esse tipo de solução pode ajudar a priorizar análises de crédito, reduzir trabalho manual e mitigar risco de inadimplência. Em um ambiente real, ela nunca deveria aprovar ou negar crédito sozinha sem regras de governança, auditoria e análise de viés.

## Exemplo 2, IA não supervisionada

Arquivo: `exemplos/nao_supervisionado_kmeans_clientes.py`

O modelo usa uma base fictícia de clientes com:

- compras por mês
- gasto médio
- dias desde a última compra

Nesse caso, não existe rótulo pronto dizendo se o cliente é VIP, recorrente ou está em risco. O algoritmo apenas procura grupos parecidos. Por isso é um exemplo não supervisionado.

Algoritmo usado: K-Means.

Impacto prático: esse tipo de solução pode apoiar campanhas de marketing mais direcionadas, recuperação de clientes inativos e melhor alocação de orçamento.

## Validação dos dados

Antes de rodar os modelos, os scripts validam:

- tipos numéricos
- valores nulos
- inconsistências estruturais
- possíveis outliers usando IQR

Mesmo sendo uma base pequena e fictícia, isso mostra uma prática importante: nunca assumir que os dados estão limpos.

## Observações importantes

Fato: os dados usados aqui são fictícios e servem apenas para estudo.

Inferência: os segmentos do K-Means recebem nomes depois que os grupos são encontrados, com base nos centroides.

Opinião técnica: para esse trabalho, Python puro é a melhor escolha porque reduz complexidade, facilita a apresentação em sala e deixa claro o funcionamento dos algoritmos.
